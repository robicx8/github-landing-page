Launchpad is a single-file landing page for open-source projects. Push it to GitHub, connect it to Netlify, and you're live in under a minute.

Get started → ★ Star on GitHub

~/my-project

$ git add index.html
$ git commit -m "Add landing page"
$ git push origin main
✔ Deployed to https://my-project.netlify.app▌
01

Zero build step

Plain HTML and CSS. No frameworks, no bundlers, no node_modules to babysit.

02

Git-powered deploys

Every push to main ships to production. Every pull request gets a preview.

03

Fast everywhere

Served from a global edge network, so it loads instantly wherever your users are.

04

Easy to make yours

Swap the copy, change two color variables, and it's your brand in five minutes.

Up and running in three steps

  1. Fork or clone the repository to your GitHub account.
  2. Edit index.html with your project's name and pitch.
  3. Push — Netlify picks up the change and deploys automatically.
